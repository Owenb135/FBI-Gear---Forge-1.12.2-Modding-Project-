
# FBI Gear

FBI gear, my very first mod, is a police themed mod including many diffrent items and features. The mod pairs well with the MrCrayfish Gun Mod.


## Features

- Night Vision Glasses
- Titanium Sword
- Titanium Axe
- Dyed Iron
- Etc
